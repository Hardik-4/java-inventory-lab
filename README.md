# Java Inventory / OOP Lab

Small OOP lab covering circles, a file-backed inventory manager, and reversing a text file.

## Features

- `Circle` with area / circumference (`Math.PI`)
- `InventoryManager` with add / remove / view + CSV persistence
- Text-file line reversal utility
- Unified menu entry point

## Run

```bash
javac -d out $(find src -name "*.java")
java -cp out inventory.Main
```

Sample data files `input.txt` and `inventory.txt` are included.
